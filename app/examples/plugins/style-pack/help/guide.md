This pack keeps a translation in one voice.

- **No slang** marks «круто» and «ок» and offers «чудово» and «добре».
- **Address «Sir»** asks for a polite address when the original has one.
- **Names fit the menu** is an error for names longer than 24 characters.
- **Tidy punctuation** (menu *Інструменти*) shows every change before it is made, and it can be undone.

The rules are an advice; each project sets its own level in *Правила QA*.
