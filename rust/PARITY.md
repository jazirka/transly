# Паритет нативної програми з веб-версією

Мета: нативна `transly-app` виглядає як веб `app/`; нереалізоване — заглушки.

## Як порівнювати (повторюється за хвилину)
1. Дані: `python3 rust/parity/make_fixture.py /tmp/parity/fixture` (гра `ParityGame` + `project.json`).
2. Веб: `cd app && npx vite build --outDir /tmp/parity/dist && npx vite preview --outDir /tmp/parity/dist --port 4301 --strictPort`, потім `FIX=/tmp/parity/fixture OUT=/tmp/parity/web node ../rust/parity/web_shots.cjs` (скрипт копіюється в `app/test-ui/`, бо потрібен `playwright`).
3. Натив: `cd rust && XDG_DATA_HOME=/tmp/parity/xdg TRANSLY_FIXTURE=/tmp/parity/fixture TRANSLY_SHOTS=/tmp/parity/native cargo test -p transly-app parity_shots -- --ignored`.
4. Пари: `convert web/N.png native/N.png -resize 50% +append pairs/N.png`.

## Зроблено в цьому проході (2026-11-25)
- «Внески»: картка з заголовком «ВНЕСКИ N», рядки з аватаром, іменем («Хтось» без імені), датою, позначкою й кнопками «+ − ✓ 🗑» (як у вебі).
- Права колонка за замовчуванням у «Редагуванні» — лише «Пов'язане» (було ще й «Активність»).
- Вкладки файлів: хрестик лише на активній і при наведенні.
- Лічильник довжини перекладу зелений, коли в межах (як у вебі).
- Дзвоник сповіщень у верхній панелі (заглушка «розділ у розробці»).

## Відомі розбіжності (не виправлено)
- Колір теми: веб бере відтінок із назви проєкту від **теки гри** («ParityGame»), натив — з назви в `project.json` («Parity Game»); звірити алгоритм імені.
- Аватар проєкту: у вебі літера (P) у зеленому колі, у нативі «PG».
- У нативі в картці «Пов'язане» є форма «слово/переклад + Додати термін» (у вебі додавання терміна лише в лівій панелі).
- Заголовки карток праворуч мають «—» завжди (у вебі лише при наведенні).
- Мітка «назва» у списку рядків: веб — текст кольору теми, натив — з фоном.
- Не звірено (знімки є лише для таблиці, редагування, сцени, лівих і правих панелей): головне меню, меню проєкту/гілки/запуску, діалоги (Налаштування, Збірка, Злиття, Автозаповнення), світла/темна, hover/focus-стани.
